Single sign-on moves into the Admin page: add Tinyauth, Google or any OpenID Connect provider there, each with its own sign-in button.

## Upgrade

```
docker pull ghcr.io/spacegoose02/sports-tracker:1.7.0
```

On Unraid, click **Update** on the container. Your data in appdata carries over. There are no new settings.

If you already use SSO through `SSO_ISSUER`, `SSO_CLIENT_ID` and the other `SSO_*` variables, nothing breaks. The first time 1.7.0 starts, it copies them into **Admin > Sign-in providers** as a provider, and existing Tinyauth users stay linked. After that you manage it in Admin, and you can remove the variables. A provider you delete in Admin won't come back from them.

`PUBLIC_URL` should still be set, because every provider uses `<PUBLIC_URL>/auth/sso/callback` as its redirect URI.

## What's new

**Sign-in providers in Admin**
- Add, edit and remove sign-in providers in **Admin > Sign-in providers**. Each one gets its own "Sign in with …" button on the account page (#48)
- Works with Tinyauth, Google (`https://accounts.google.com`) and any OpenID Connect provider. Client secrets stay on the server and are never sent back to the browser (#48)
- Per provider, choose whether anyone can create an account by signing in, or only people who already have an account with the same email. You can also hide a provider from the sign-in page (#48)
- Admin shows the callback URL to paste into the provider, with a Copy button (#48)

**Accounts**
- One account can link more than one provider, such as Tinyauth and Google. A sign-in whose email matches an existing account links to that account (#48)
