## Upgrade

```
docker pull ghcr.io/spacegoose02/sports-tracker:1.6.0
```

On Unraid, click **Update** on the container. Your data in appdata carries over.

**Set `PUBLIC_URL` when you deploy.** The sitemap, `robots.txt` and share previews now build their links from it, so set it to the site's public address, for example `PUBLIC_URL=https://cfb.sgiu.net`. It's already in the Unraid template (Public URL) and `.env.example`. If it's left unset, links come from the incoming request, which can be wrong behind a reverse proxy.
