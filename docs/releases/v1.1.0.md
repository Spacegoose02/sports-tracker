CFB Tracker is now **Stat Scraps**, with Scrappy, an AI sidekick that answers sports questions and sends you a morning recap. This release also adds play-by-play, highlights, a TV wall, a playoff hub with family leagues, and Spanish.

## Upgrade

```
docker pull ghcr.io/spacegoose02/sports-tracker:1.1.0
```

On Unraid, click **Update** on the container. Your data in appdata carries over. To use the new settings below on an existing install, re-apply the template from `unraid/cfb-tracker.xml` or add the variables by hand.

## What's new

**Stat Scraps and Scrappy**
- New name and look: Stat Scraps, with Scrappy as the mascot (#21)
- Scrappy, an AI sports chat bubble on every page (#22). It runs on Claude (`ANTHROPIC_API_KEY`) or on your own Ollama server (`OLLAMA_URL`), and can search the web through Ollama or SearXNG (#30)
- Scrappy's daily morning recap of your followed teams (#28)

**Watching games**
- Live play-by-play, a momentum chart, a drive tracker and a compare tool (#26)
- Game highlights and a full-screen TV wall mode (#25)
- "Where to watch" links straight to the game's BingeBandit Live TV channel (#24)
- Admin editor for radio and TV info (#23)

**Playoffs and family**
- Playoff hub, family bracket challenge and family leagues (#27)

**Everyone**
- Spanish language option and an accessibility pass (#29)

## New settings

All optional, and all listed in the Unraid template and `.env.example`:

- Scrappy: `ANTHROPIC_API_KEY`, `SCRAPPY_MODEL`, `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_API_KEY`, `SCRAPPY_PROVIDER`, `OLLAMA_TIMEOUT_SECONDS`, `SEARXNG_URL`, `SCRAPPY_RATE_PER_MINUTE`, `SCRAPPY_RATE_PER_DAY`
- Morning recap: `DAILY_RECAP` (on by default), `RECAP_NOW_PER_HOUR`

Without an AI provider set, the site works as before and Scrappy stays hidden.
