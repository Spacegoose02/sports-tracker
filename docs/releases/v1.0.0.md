The first tagged release of CFB Tracker: a self-hosted hub for college football first, with the other big sports alongside it.

## Install

```
docker pull ghcr.io/spacegoose02/sports-tracker:1.0.0
```

On Unraid, use the Docker tab template in `unraid/cfb-tracker.xml` (see **Running with Docker** in the README). Set `ADMIN_PASSWORD` and `SESSION_SECRET`; your data lives in `/mnt/user/appdata/cfb-tracker`.

## What's in it

**Scores and games**
- Live scores that update on their own, and a full game page with drives, box score and win probability
- "Where to Listen" radio info on game pages
- Betting lines page

**Sports**
- College football, plus NFL, NBA, MLB, NHL, college basketball, UFC and NASCAR
- Follow any number of teams in any sport, with news for the teams you follow

**Stats and research**
- Player pages, stat leaders, NFL fantasy, and richer rankings, standings and team pages
- Recruiting and transfer portal page (Top Recruits, Class Rankings and Transfer Portal with a free CFBD key)

**Accounts and alerts**
- Accounts with email sign-up or single sign-on (Tinyauth or any OpenID Connect provider)
- Push alerts when followed teams' games start and end
- Calendar feeds for your teams

**Look and feel**
- Installable as a phone app (PWA), faster on mobile
- Sports themes with a theme picker, plus light mode
- Kids Zone: kid mode, celebrations, pick'em, trivia, stickers and a countdown

**Integrations**
- Home Assistant integration with live scorecards (install through HACS)
- Caching ESPN relay for BingeBandit

**Running it**
- Prebuilt image for amd64 and arm64 on GitHub Container Registry
- Unraid Docker tab template listing every setting
- Health check at `/healthz`, PUID/PGID support, persistent data volume

**Security**
- Outside content is escaped, and admin login stays locked until a real password and session secret are set
