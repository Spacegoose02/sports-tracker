Your Dynacat F1 widgets work again, now backed by Stat Scraps' own Formula 1 feed.

## Upgrade

```
docker pull ghcr.io/spacegoose02/sports-tracker:1.9.0
```

On Unraid, click **Update** on the container. Your data in appdata carries over. There are no new settings.

Then swap your F1 widgets in Dynacat for the ones in `dynacat-f1-widgets.yaml`, and set the host to wherever Stat Scraps runs. The old widgets read f1api.dev, which no longer loads, so they showed "This widget couldn't load".

## What's new

**Formula 1 for dashboards**
- A new `/api/f1` feed with the next race and its sessions, the last race's results, and the drivers' and constructors' standings. It comes from ESPN, refreshes every 10 minutes and needs no key (#52)
- `dynacat-f1-widgets.yaml` has four ready-made Dynacat/Glance widgets that read from it. The feed is documented in `docs/dashboards.md` (#52)
